EmbedManager

A versatile JavaScript library for embedding various content types (YouTube, Vimeo, Twitch, CodePen, and websites) with lazy loading capabilities and responsive design.

Get Started GitHub

Features

Everything you need to embed content efficiently with lazy loading

Multiple Content Types

Support for YouTube, Vimeo, Twitch, CodePen, and website embeds with intelligent handling for each platform.

Lazy Loading

Uses Intersection Observer API to load embeds only when they come into view, improving page performance.

Responsive Design

Automatically adapts to different screen sizes with configurable dimensions for optimal display on any device.

Secure Embedding

Website embeds use sandbox attributes for enhanced security while maintaining functionality.

Lightweight & Fast

Zero dependencies and minimal footprint with automatic CSS injection for seamless integration.

Accessibility Built-in

Configurable iframe titles and semantic HTML structure ensure your embedded content is accessible to all users.

Getting Started

Up and running in three simple steps

1. Include the Library

Add the EmbedManager script to your HTML page:

<script src="https://cdn.jsdelivr.net/gh/peterbenoit/EmbedManager@latest/src/lib/embedManager.js"></script>

Or install via npm:

npm install embed-manager

2. Create Embed Containers

Add containers with the embed-container class and data attributes:

<div class="embed-container"
     data-src="https://www.youtube.com/embed/dQw4w9WgXcQ"
     data-type="youtube"
     data-title="Video Title"
     data-width="600px"
     data-height="315px"></div>

3. Automatic Initialization

EmbedManager automatically initializes and handles lazy loading:

// No additional JavaScript needed!
// EmbedManager handles everything automatically
